Stochastic Multiplier — Multi-Precision Interactive Simulator

LFSR, RAMP, Even-Distribution (ED), and Sobol/quasirandom SNGs for unipolar stochastic multiplication. The 8-bit curves use the completed notebook results; 16-bit and 32-bit modes use scalable live sampling.

2. SNG architectures

LFSR
Maximal-length
8-bit: notebook P2 = [7,5,4,1]. 16-bit: x^16 + x^14 + x^13 + x^11 + 1. 32-bit: x^32 + x^22 + x^2 + x + 1. A and B are separate instances with different non-zero seeds.
RAMP
Scalable
Uses r(i)=i/L and compares it with value/(2^N−1). The same deterministic ramp is used for both operands, so stream dependence is intentionally measured.
ED
8-bit verified
8-bit mode uses the notebook's hardware-faithful B=1, V=16, K=4 construction. 16/32-bit modes use a scalable even-distribution software model; they are not claimed to be the same hardware circuit.
Sobol
Scalable
First-dimension low-discrepancy construction with 32-bit direction numbers. Threshold comparison is performed at the selected input precision.

8. Methodology and scalability notes

8-bit

All 256 × 256 operand pairs are evaluated for every SNG and every L. This is the exhaustive baseline from the notebook.

16-bit

The complete 65,536 × 65,536 space is too large for interactive exhaustive evaluation. The simulator uses reproducible random + structured sampling.

32-bit

The input-pair space is 2^64. The simulator uses sampled pairs with the same stochastic AND multiplication and error definitions.
Unipolar representation: P = value / (2^N - 1) Multiplication: S_out[i] = S_A[i] AND S_B[i] Decoded product: P_SC × (2^N - 1)^2 Normalized error: P_SC - P_exact Dependence error: P_AND - P_A × P_B
