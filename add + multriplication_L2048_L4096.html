Finite-stream resolution check
For an N-bit unipolar value, the theoretical 1-density is value/(2N−1). The expected number of 1s in an L-bit stream is L × density. If this value is far below 1, getting zero 1s is a real finite-stream outcome — it is not automatically an SNG implementation error.

2. SNG architectures

LFSR
Verified
8-bit reproduces the notebook Fibonacci-style state sequence and comparator convention. 16/32-bit use the same recurrence with width-appropriate presets and independently controlled non-zero seeds for A and B.
RAMP
Verified
Uses the notebook construction r(i)=i/L and compares it with value/(2N−1). A and B intentionally share the same ramp, so correlation/dependence is measurable.
ED
8-bit notebook-faithful
8-bit is the exact notebook B=1, V=16, K=4 implementation, including seeds 42/43 and its generated 1024-bit sequences; for L>1024 the simulator uses the scalable even-distribution model. 16/32-bit are explicitly a scalable even-distribution software model because the notebook does not define a 16/32-bit ED hardware architecture.
Sobol
Notebook-derived
Uses the notebook's first-dimension Sobol sequence, the same 32-bit direction numbers, and A/B phase offsets 0/1. For 16/32-bit, the same sequence is thresholded at the selected N-bit precision.
8-bit ED
Exact notebook construction and embedded generated streams for seeds 42 and 43.
8-bit Sobol
Exact notebook sequence and thresholding, including the A=0 / B=1 phase offset used in multiplication.
16/32-bit ED
Scalable software model only. Do not label these results as the notebook's hardware-faithful ED results.
16/32-bit Sobol
Algorithmically extended from the notebook's first-dimensional sequence; short L can still yield zero 1s for tiny normalized values.

8. Methodology and scalability notes

8-bit

All 256 × 256 operand pairs are evaluated for every SNG and every L. This is the exhaustive baseline from the notebook.

16-bit

The complete 65,536 × 65,536 space is too large for interactive exhaustive evaluation. The simulator uses reproducible random + structured sampling.

32-bit

The input-pair space is 2^64. The simulator uses sampled pairs with the same stochastic AND multiplication and error definitions.
Unipolar representation: P = value / (2^N - 1) Multiplication: S_out[i] = S_A[i] AND S_B[i] Decoded product: P_SC × (2^N - 1)^2 Normalized error: P_SC - P_exact Dependence error: P_AND - P_A × P_B Percentage error: 100 × (SC_result - exact_product) / exact_product (0 when exact_product = 0)

6. Methodology

MUX

With a 50% select, the ideal relation is \(P_{MUX}=(P_A+P_B)/2\), so the recovered sum is \(2P_{MUX}\).

OR

OR gives \(P_{OR}=P_A+P_B-P_AP_B\). It is not equal to ordinary addition.

SNGs

LFSR, ED, and Sobol use the same SNG functions and A/B configurations as the multiplication simulator.
