4. What the error metrics mean
Normalized multiplication error
e_norm = pAND − (A/255)(B/255)
This is the stochastic-computing error used in the exhaustive pair search. Its absolute value is measured relative to the normalized [0,1] representation.
Actual product error
e_rel = |PSC − Pactual| / |Pactual| × 100%
This is the conventional percentage error of the decoded integer product. It is the metric you would normally quote when comparing the final numerical result.
Why they are connected
PSC = pAND × 255²    Pactual = A×B
Because pideal = (A/255)(B/255) = (A×B)/255², the signed integer product error is exactly e_norm × 255².
Important distinction
e_norm ≠ relative error
Normalized error is an absolute error on the normalized scale. Relative percentage error divides by the particular actual product, so it can become very large for small products and is undefined when A×B = 0.

8. LFSR polynomial definitions
All three configurations are 8-bit maximal-length Fibonacci LFSRs. A polynomial label (P1/P2/P3) identifies the feedback-tap set; a seed identifies the initial non-zero LFSR state. Each configuration has a 255-state period.
P1
Feedback = s₇ ⊕ s₅ ⊕ s₄ ⊕ s₃
Taps: [7, 5, 4, 3]
The feedback bit is the XOR of state bits 7, 5, 4 and 3.
P2
Feedback = s₇ ⊕ s₅ ⊕ s₄ ⊕ s₁
Taps: [7, 5, 4, 1]
The feedback bit is the XOR of state bits 7, 5, 4 and 1.
P3
Feedback = s₇ ⊕ s₆ ⊕ s₁ ⊕ s₀
Taps: [7, 6, 1, 0]
The feedback bit is the XOR of state bits 7, 6, 1 and 0.
LFSR notation: Pk–seed means “polynomial Pk with that seed”. Example: P2–198 = P2 taps [7,5,4,1], initialized with state 198.
