Experimental stochastic final-adder path

Experimental approximation
Final Rows R1, R2→Value Encoding→Sobol SNGs→MUX Addition→Density Estimate→Decoded Result

Encode each full row as p=R/65,535; emit 1 iff p>q/2³² (strict comparison). The MUX is Zᵢ=Sᵢ?Xᵢ:Yᵢ and the raw estimate is 2·65,535·ones(Z)/L. A balanced select has the ideal average relation only under suitable independence; balance alone is not enough. The rounded result uses nearest integer, ties upward. L=16 or 32 is short relative to the 16-bit range, so quantization and stream dependence can cause large errors.

How the Sobol generator is defined

Unscrambled Sobol digital net, zero-based index n. Let g=n⊕(n≫1), and q=⊕Vⱼ for every set bit gⱼ; point qₙ is the resulting uint32 divided by 2³². Dimension 1 uses Vⱼ=2³²⁻ʲ. Dimension 2 uses primitive polynomial x+1, s=1, m₁=1. Dimension 3 uses x²+x+1, s=2, a=1, m₁=1, m₂=3. Recurrence: Vⱼ=Vⱼ₋₂⊕(Vⱼ₋₂≫2)⊕Vⱼ₋₁. Start index advances the point index; no scrambling is implemented. Separate dimensions do not prove statistical independence; finite-stream dependence is measured above.

Fair synthesis checklist

Fair synthesis checklist

  • Use identical target technology, constraints, clock assumptions, synthesis and implementation flow.
  • Include Dadda partial products and all compressor cells in both designs.
  • Include Sobol direction logic, comparators, stream registers, select MUX, ones counter, scaling/rounding and control in the proposed design.
  • Report the stochastic stream length and actual serial latency; disclose throughput and area/power for the full block.
  • Compare critical path and latency separately. A browser cycle count is only an algorithmic stream length.
