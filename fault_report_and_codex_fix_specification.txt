FAULT 4: edStreamScalable() (16-bit and 32-bit ED) zeroes out small inputs and phase-locks at 50%
========================================================================
LOCATION:
- Function: edStreamScalable(value, L, width, seed)

ROOT CAUSE:
1. Math.floor(((i + 1) * value) / max) truncates total ones to $\lfloor L \cdot \text{value} / \text{max} \rfloor$, producing zero ones whenever $\text{value} < \text{max} / L$ and introducing a negative representation bias.
2. It generates a periodic pulse train instead of a bit-reversed quasi-random even-distribution sequence.
3. For seed = 43 (Stream B), it circularly shifts by 43 % L (an odd shift). At 50% density ($P = 0.5$), Stream A (seed = 42) is [0, 1, 0, 1, ...] and Stream B (seed = 43) is [1, 0, 1, 0, ...]:
   - Multiplication (A AND B) outputs 0 everywhere.
   - Addition MUX with sel = [1, 0, 1, 0, ...] outputs 1 everywhere (100% ones, doubling the true sum).

FIX INSTRUCTIONS:
Replace edStreamScalable(value, L, width, seed) with a bit-reversed quasi-random permutation and seed-dependent scramble:
```javascript
function edStreamScalable(value,L,width,seed){
  const max=maxForBits(width);
  if(value<=0)return new Array(L).fill(0);
  if(value>=max)return new Array(L).fill(1);
  const targetOnes=Math.round((value/max)*L);
  const logL=Math.round(Math.log2(L));
  // Use distinct bit-reversal scrambling per seed so A (42) and B (43) are uncorrelated and evenly distributed
  const mask=(seed===42?0:((seed*2654435761)>>>(32-logL)))&(L-1);
  const out=new Array(L);
  for(let i=0;i<L;i++){
    let rev=0,x=i;
    for(let b=0;b<logL;b++){rev=(rev<<1)|(x&1);x>>=1;}
    const rank=(seed===42)?rev:(((rev*5+1)&(L-1))^mask);
    out[i]=rank<targetOnes?1:0;
  }
  return out;
}
```
Note: Since $L$ is always a power of 2 ($16 \dots 1024$), $\text{rank} \mapsto ((\text{rev} \cdot 5 + 1) \pmod L) \oplus \text{mask}$ is a bijection on $\{0, \dots, L-1\}$, guaranteeing the exact same targetOnes count while decorrelating Stream A and Stream B across both AND and alternating MUX operations.
